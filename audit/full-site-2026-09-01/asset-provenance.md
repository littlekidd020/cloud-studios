# Cloud Studios prototype media register

Status date: 1 September 2026

## Active production-path media

The 18 files in `public/assets/cloud-studios/` are the only media referenced by the prototype. They comprise the current Cloud Studios logo and an art-directed workspace set created from Cloud Studios visual references for the selected editorial design. The images preserve the intended room type, Epsom context and service use, but this local audit cannot independently prove capture location, ownership, model consent or whether every depicted item is currently available on site.

Active groups:

- Logo: `logo.webp`
- Exterior/location: `building-v4.webp`
- Private offices: `office-o1-v4.webp`, `office-o2-v4.webp`, `office-o3-v4.webp`
- Dedicated desks: `desks-hero-v4.webp`, `desks-wide-v4.webp`, `desks-d2-v4.webp`
- Meeting rooms: `meeting-hero-v2.webp`, `meeting-2-v2.webp`, `meeting-4-v2.webp`
- Virtual office, experiences and community: `virtual-hero-v2.webp`, `experiences-hero-v3.webp`, `community-hero-v3.webp`
- Homepage mosaic: `mosaic-office-v2.webp`, `mosaic-meeting-v2.webp`, `mosaic-address-v2.webp`, `mosaic-community-v2.webp`

## Production release gate

Before public deployment, Cloud Studios should confirm in writing that each active image accurately represents the premises/service, that branding and people may be used, and that the image may be published. Replace any unverified image with approved on-site photography while preserving the existing crop, aspect ratio and editorial treatment.

## Archived variants

Twenty-nine superseded variants were moved from the public asset directory to `audit/asset-archive-2026-09-01/`. They remain recoverable locally but are excluded from the production build.
